# dotfiles
Terminal and vim setups


# Font setups

- Install `fontconfig`

NOTE: Font config dir `~/.local/share/fonts/`

- Install SF Pro, Monaco, Menlo font
    SF Pro: `https://github.com/sahibjotsaggu/San-Francisco-Pro-Fonts.git`
    Monaco: ..
    Menlo: `https://aur.archlinux.org/packages/ttf-meslo`

- Allow websites to choose their fonts
- Follow this setup if you are in ArchLinux to improve fonts rendering: `https://github.com/davgar99/arch-linux-font-improvement-guide`
